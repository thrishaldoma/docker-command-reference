QUESTION
========
## Objective

Passwords must never be written into Deployment manifests, which end up in Git. Kubernetes **Secrets** keep them separate, and Pods reference them by name. You will store a database credential in a Secret and consume it from a Pod, both as environment variables and as a mounted file.

The database password for this lab is in `/home/user/secret/db-password.txt`.

## Tasks

### Task 1: Create the Secret

Create a Secret of type `Opaque` named `db-credentials` with two keys:

- `username`: `appuser`
- `password`: the contents of `/home/user/secret/db-password.txt` (without a trailing newline)

### Task 2: Write the Deployment manifest

Create `/home/user/secret/app.yaml` with a Deployment named `secret-demo` (image `busybox:1.38.0`, container name `app`, command `sleep 3600`) that:

- sets the environment variable `DB_USER` from the Secret key `username`
- sets the environment variable `DB_PASSWORD` from the Secret key `password`
- mounts the whole Secret as a read-only volume at `/etc/db-credentials`

The manifest must **not** contain the password, in plain text or in base64.

### Task 3: Deploy and verify

Apply the manifest and wait for the Pod. Verify inside the Pod that `DB_PASSWORD` and the file `/etc/db-credentials/password` both contain the password.

## Notes

- Base64 is an encoding, not encryption: anyone who can read a Secret object can decode it. Keeping it out of manifests and Git is what matters here.

## Expected outcome

The `secret-demo` Pod gets the credential from `db-credentials` as environment variables and as files, and `app.yaml` contains no copy of the password.

ANSWER
======
```bash
cd /home/user/secret
kubectl create secret generic db-credentials \
  --from-literal=username=appuser \
  --from-literal=password="$(cat db-password.txt)"

cat > app.yaml <<'END'
apiVersion: apps/v1
kind: Deployment
metadata:
  name: secret-demo
spec:
  replicas: 1
  selector:
    matchLabels:
      app: secret-demo
  template:
    metadata:
      labels:
        app: secret-demo
    spec:
      containers:
        - name: app
          image: busybox:1.38.0
          command: ["sleep", "3600"]
          env:
            - name: DB_USER
              valueFrom:
                secretKeyRef:
                  name: db-credentials
                  key: username
            - name: DB_PASSWORD
              valueFrom:
                secretKeyRef:
                  name: db-credentials
                  key: password
          volumeMounts:
            - name: creds
              mountPath: /etc/db-credentials
              readOnly: true
      volumes:
        - name: creds
          secret:
            secretName: db-credentials
END
kubectl apply -f app.yaml
kubectl rollout status deployment/secret-demo
kubectl exec deploy/secret-demo -- sh -c 'echo "$DB_USER"; cat /etc/db-credentials/password'
```

APPROACH
========
1. Create the Secret, then check it with `kubectl get secret db-credentials -o jsonpath='{.data.password}' | base64 -d`.
2. Write `app.yaml` with `secretKeyRef` for both variables and a `secret` volume mounted at `/etc/db-credentials`.
3. `grep` your manifest for the password to make sure it is not there.
4. Apply it and check with `kubectl exec deploy/secret-demo -- sh -c 'echo $DB_PASSWORD; cat /etc/db-credentials/password'`.

HINT
====
- `kubectl create secret generic db-credentials --from-literal=username=appuser --from-file=password=/home/user/secret/db-password.txt` reads the file as the value. Make sure the file has no trailing newline, or use `--from-literal=password="$(cat file)"`.
- In the container: `env: - name: DB_PASSWORD valueFrom: secretKeyRef: {name: db-credentials, key: password}`.
- A Secret volume: `volumes: - name: creds secret: {secretName: db-credentials}` plus a `volumeMounts` entry with `readOnly: true`.

ORIGINAL SOLUTION SCRIPT (solve.sh)
===================================
#!/bin/bash
set -euo pipefail
cd /home/user/secret
kubectl create secret generic db-credentials --from-literal=username=appuser --from-literal=password="$(cat db-password.txt)"
cat > app.yaml <<END
apiVersion: apps/v1
kind: Deployment
metadata:
  name: secret-demo
spec:
  replicas: 1
  selector:
    matchLabels:
      app: secret-demo
  template:
    metadata:
      labels:
        app: secret-demo
    spec:
      containers:
        - name: app
          image: $IMAGE_BUSYBOX
          command: ["sleep", "3600"]
          env:
            - name: DB_USER
              valueFrom:
                secretKeyRef:
                  name: db-credentials
                  key: username
            - name: DB_PASSWORD
              valueFrom:
                secretKeyRef:
                  name: db-credentials
                  key: password
          volumeMounts:
            - name: creds
              mountPath: /etc/db-credentials
              readOnly: true
      volumes:
        - name: creds
          secret:
            secretName: db-credentials
END
kubectl apply -f app.yaml
kubectl rollout status deployment/secret-demo --timeout=300s
