QUESTION
========
## Problem: Ownership and Permission Audit for Sensitive Files

In a security-focused DevOps environment, managing file ownership is just as critical as managing file permissions.

You are tasked with correcting the ownership of files in a simulated secure log environment located at:

```
/home/user/task_8/
├── audit.log
└── confidential/
    ├── file1
    └── file2
```

Note: Use password `user@123!` if required for sudo access.

Initially, all files are owned by `root:root`. Your job is to update the ownership as follows:

1. The `audit.log` file must be owned by user `nobody` and group `nogroup` (`nobody:nogroup`).
2. All files inside the `confidential/` folder (`file1` and `file2`) must be owned by user `nobody`.

## Notes

- Change only the ownership. Do not delete, recreate or edit the files.
- Changing ownership of files you do not own needs `sudo`.

## Expected outcome

`audit.log` is owned by `nobody:nogroup`, and `confidential/file1` and `confidential/file2` are owned by `nobody`. The file contents are unchanged.

ANSWER
======
```bash
cd /home/user/task_8
sudo chown nobody:nogroup audit.log          # password: user@123!
sudo chown nobody confidential/file1 confidential/file2
ls -lR /home/user/task_8
```

`sudo chown nobody confidential/*` works too.

APPROACH
========
1. Look at the current ownership with `ls -lR /home/user/task_8`.
2. Change `audit.log` to `nobody:nogroup` with `sudo chown`.
3. Change the owner of both files in `confidential/` to `nobody` (one command can take several files, or use a wildcard).
4. Run `ls -lR` again to confirm.

HINT
====
- `chown` changes ownership. The form `chown user:group file` sets both the owner and the group.
- Only root can give files away to another user, so prefix the command with `sudo`.
- `ls -l` shows the owner and group of each file.

ORIGINAL SOLUTION SCRIPT (solve.sh)
===================================
#!/bin/bash
set -euo pipefail
cd /home/user/task_8
echo "$SUDO_PASSWORD" | sudo -S -p '' chown nobody:nogroup audit.log
echo "$SUDO_PASSWORD" | sudo -S -p '' chown nobody confidential/file1 confidential/file2
