QUESTION
========
## Objective

A designer handed you a single HTML page in `/home/user/site/index.html`. Package it as a container image with your own `Dockerfile`, build it, run it and check that the page is served.

## Tasks

### Task 1: Write the Dockerfile

Create `/home/user/site/Dockerfile` that uses exactly these four kinds of instructions:

- `FROM`: start from the Python image `python:3.15.0-slim`
- `WORKDIR`: use `/srv/site` as the working directory
- `COPY`: copy `index.html` into the working directory
- `CMD`: start Python's built-in web server on port `8000`, serving the working directory, in exec (JSON array) form:

```
CMD ["python3", "-m", "http.server", "8000"]
```

### Task 2: Build the image

Build the image from `/home/user/site` and tag it `my-site:1.0`.

### Task 3: Run and verify

Run a container from `my-site:1.0` in the background:

- container name: `site`
- host port `8081` mapped to container port `8000`

Then check with `curl http://localhost:8081` that your page is returned.

## Notes

- Leave the `site` container running when you submit.
- The image tag must be exactly `my-site:1.0`.

## Expected outcome

An image `my-site:1.0` built from your Dockerfile, and a running container `site` that serves `index.html` on port 8081.

ANSWER
======
```bash
cd /home/user/site
cat > Dockerfile <<'END'
FROM python:3.15.0-slim
WORKDIR /srv/site
COPY index.html .
CMD ["python3", "-m", "http.server", "8000"]
END
docker build -t my-site:1.0 .
docker run -d --name site -p 8081:8000 my-site:1.0
curl http://localhost:8081
```

APPROACH
========
1. `cd /home/user/site` and create the `Dockerfile` with `nano`, one instruction per line in the order FROM, WORKDIR, COPY, CMD.
2. Run `docker build -t my-site:1.0 .`
3. Run `docker run -d --name site -p 8081:8000 my-site:1.0`
4. `curl http://localhost:8081` and look for the page text.

HINT
====
- Instructions are written one per line, for example `WORKDIR /srv/site`.
- `COPY index.html .` copies into the working directory.
- `docker build -t NAME:TAG DIR` builds and tags an image; `docker images` lists images.

ORIGINAL SOLUTION SCRIPT (solve.sh)
===================================
#!/bin/bash
set -euo pipefail
cd /home/user/site
cat > Dockerfile <<END
FROM $IMAGE_PYTHON
WORKDIR /srv/site
COPY index.html .
CMD ["python3", "-m", "http.server", "8000"]
END
docker build -q -t my-site:1.0 . >/dev/null
docker run -d --name site -p 8081:8000 my-site:1.0 >/dev/null
for _ in $(seq 1 30); do curl -sf http://localhost:8081 >/dev/null && break; sleep 1; done
