QUESTION
========
## Objective

A new team member joins the DevOps team for an exam project. You will create their account, a team group, and a shared project directory that only the team can use.

Password for sudo: `user@123!`

## Tasks

### Task 1: Create the group

Create a group named `devops`.

### Task 2: Create the user

Create a user named `examuser` with:

- a home directory at `/home/examuser`
- `/bin/bash` as the login shell

### Task 3: Add the user to the group

Add `examuser` to the `devops` group as a supplementary group. `examuser` keeps its own primary group.

### Task 4: Create the project directory

Create the directory `/srv/devops-project` and configure it so that:

- the owner is `examuser` and the group is `devops`
- the owner and the group can read, write and enter the directory
- everyone else has no access at all
- new files created inside it automatically belong to the `devops` group (the setgid bit)

In octal notation, the required mode is `2770`.

## Notes

- All of these commands need `sudo`.
- The checker verifies the result by actually creating a file as `examuser` and by checking that other users are kept out.

## Expected outcome

`examuser` exists, is a member of `devops`, and `/srv/devops-project` is owned by `examuser:devops` with mode `2770`.

ANSWER
======
```bash
sudo groupadd devops                         # password: user@123!
sudo useradd -m -s /bin/bash examuser
sudo usermod -aG devops examuser
sudo mkdir -p /srv/devops-project
sudo chown examuser:devops /srv/devops-project
sudo chmod 2770 /srv/devops-project
id examuser
ls -ld /srv/devops-project                   # drwxrws--- examuser devops
```

APPROACH
========
1. Create the group with `sudo groupadd devops`.
2. Create the user with a home directory and bash as shell using `sudo useradd`.
3. Add the user to `devops` with `sudo usermod -aG`.
4. Create `/srv/devops-project`, set its owner and group with `chown`, and its mode with `chmod 2770`.
5. Verify with `id examuser`, `getent group devops` and `ls -ld /srv/devops-project` (the mode shows as `drwxrws---`).

HINT
====
- `groupadd` creates groups, `useradd` creates users (`-m` makes the home directory, `-s` sets the shell).
- `usermod -aG GROUP USER` appends a supplementary group. Without `-a` it replaces the user's groups.
- `chown user:group DIR` and `chmod 2770 DIR`.
- Check your work with `id examuser` and `ls -ld /srv/devops-project`.

ORIGINAL SOLUTION SCRIPT (solve.sh)
===================================
#!/bin/bash
set -euo pipefail
s() { echo "$SUDO_PASSWORD" | sudo -S -p '' "$@"; }
s groupadd devops
s useradd -m -s /bin/bash examuser
s usermod -aG devops examuser
s mkdir -p /srv/devops-project
s chown examuser:devops /srv/devops-project
s chmod 2770 /srv/devops-project
