QUESTION
========
## Objective

Before you can troubleshoot a network problem, you need to know how the machine itself is connected: its IP address and subnet, where traffic leaves the subnet, and which services listen for connections. In this lab you collect those facts with standard Linux commands, record the commands, and interpret what you see.

Password for sudo: `user@123!`

## Tasks

### Task 1: Collect the facts

Create `/home/user/network-report.txt` with exactly these five lines, filled in with the real values of this machine:

```
interface=<name of the network interface that has the machine's IPv4 address, not lo>
ip_address=<IPv4 address of that interface, without the prefix>
prefix_length=<prefix length of that address, for example 24>
default_gateway=<IPv4 address of the default route's gateway>
listening_ports=<all TCP ports in LISTEN state, as a comma separated list in ascending order>
```

### Task 2: Record the commands

Create `/home/user/commands.txt` with the commands you used:

```
ip_command=<command that shows the IP address and prefix>
route_command=<command that shows the routing table>
ports_command=<command that shows the listening TCP ports>
```

### Task 3: Interpret the output

`/home/user/questions.txt` contains four multiple-choice questions about what you found. Create `/home/user/interpretation.txt` with one line per question in the form `Q1=B`.

## Notes

- Use the modern `ip` and `ss` commands where you can. The older `ifconfig`, `route` and `netstat` are installed too.
- Some services listen only on `127.0.0.1`. They still count as listening ports.

## Expected outcome

Three files that describe the interface, address, subnet, gateway and listening ports, how you found them, and what they mean.

ANSWER
======
```bash
ip a                 # interface eth0 with something like inet 172.18.0.3/16
ip route             # default via 172.18.0.1 dev eth0
ss -tln              # LISTEN on 0.0.0.0:8080, 127.0.0.1:5432 and others
```

Write the values you see (yours will differ):

```bash
cat > /home/user/network-report.txt <<'END'
interface=eth0
ip_address=172.18.0.3
prefix_length=16
default_gateway=172.18.0.1
listening_ports=2222,5432,8080
END

cat > /home/user/commands.txt <<'END'
ip_command=ip addr show
route_command=ip route
ports_command=ss -tln
END

cat > /home/user/interpretation.txt <<'END'
Q1=B
Q2=A
Q3=C
Q4=B
END
```

Why: the prefix length counts the network bits of the address (Q1=B); the default route is used for every destination without a more specific route (Q2=A); `0.0.0.0:8080` accepts connections on every interface (Q3=C); `127.0.0.1:5432` is reachable only from this machine (Q4=B).

APPROACH
========
1. Run `ip a` and find the interface other than `lo`. Note its name, address and prefix length.
2. Run `ip route` and note the address after `default via`.
3. Run `ss -tln` and collect the port numbers from the "Local Address:Port" column. Sort them.
4. Write `network-report.txt` and `commands.txt` with `nano`.
5. Read `questions.txt`, think about what each value means, and write `interpretation.txt`.

HINT
====
- `ip addr show` (short: `ip a`) lists interfaces with addresses like `172.18.0.3/16`. The number after the slash is the prefix length.
- `ip route` shows the routing table. The line that starts with `default via` names the gateway.
- `ss -tln` lists listening TCP sockets with numeric ports. Add `-p` (with `sudo`) to see which process owns each socket.

ORIGINAL SOLUTION SCRIPT (solve.sh)
===================================
#!/bin/bash
set -euo pipefail
iface=$(ip -o -4 addr show | awk '$2 != "lo" {print $2; exit}')
cidr=$(ip -o -4 addr show dev "$iface" | awk '{print $4; exit}')
gw=$(ip route | awk '/^default/ {print $3; exit}')
ports=$(ss -H -tln | awk '{n=split($4,a,":"); print a[n]}' | sort -n | uniq | paste -sd, -)
cat > /home/user/network-report.txt <<END
interface=$iface
ip_address=${cidr%/*}
prefix_length=${cidr#*/}
default_gateway=$gw
listening_ports=$ports
END
printf 'ip_command=ip addr show\nroute_command=ip route\nports_command=ss -tln\n' > /home/user/commands.txt
printf 'Q1=B\nQ2=A\nQ3=C\nQ4=B\n' > /home/user/interpretation.txt
