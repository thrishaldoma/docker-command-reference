QUESTION
========
## Objective

Hard-coded values make a configuration useful for exactly one situation. **Input variables** let the same code serve every environment, a **.tfvars** file holds the values for one environment, and **outputs** print the useful results after an apply. You will parameterize a small configuration and apply it for a staging environment.

## Tasks

Work in `/home/user/tf/app-config` (create it).

### Task 1: Declare the variables

In `variables.tf`, declare three variables, each with a `type` and a `description`:

| Name | Type | Default |
| --- | --- | --- |
| `environment` | `string` | none (required) |
| `owner` | `string` | none (required) |
| `replicas` | `number` | `1` |

### Task 2: Use them

In `main.tf`, using the `random` and `local` providers:

- a `random_pet` resource named `app` with `prefix = var.environment`
- a `local_file` resource named `config` that writes `${path.module}/app.conf` with exactly these four lines:

```
environment=<environment>
owner=<owner>
replicas=<replicas>
app_name=<the random_pet id>
```

### Task 3: Add outputs

In `outputs.tf`, declare:

- `app_name`: the `random_pet` id
- `config_path`: the `filename` of the `local_file`

### Task 4: Apply with a tfvars file

Create `staging.tfvars` with `environment = "staging"`, `owner = "platform-team"` and `replicas = 3`. Initialize, then apply with that file. Do not type the values on the command line.

### Task 5: Use an output

Save the value of the `app_name` output, without quotes, to `/home/user/tf/app-config/app-name.txt`.

## Notes

- `terraform output -raw NAME` prints an output's value without quotes.

## Expected outcome

The configuration is applied with the staging values from `staging.tfvars`, `app.conf` contains them, and the outputs show the generated app name and the config path.

ANSWER
======
```bash
mkdir -p /home/user/tf/app-config && cd /home/user/tf/app-config
cat > variables.tf <<'END'
variable "environment" {
  type        = string
  description = "Name of the environment, for example staging"
}

variable "owner" {
  type        = string
  description = "Team that owns the application"
}

variable "replicas" {
  type        = number
  description = "Number of application replicas"
  default     = 1
}
END
cat > main.tf <<'END'
terraform {
  required_providers {
    local  = { source = "hashicorp/local" }
    random = { source = "hashicorp/random" }
  }
}

resource "random_pet" "app" {
  prefix = var.environment
}

resource "local_file" "config" {
  filename = "${path.module}/app.conf"
  content  = <<-EOT
    environment=${var.environment}
    owner=${var.owner}
    replicas=${var.replicas}
    app_name=${random_pet.app.id}
  EOT
}
END
cat > outputs.tf <<'END'
output "app_name" {
  value = random_pet.app.id
}

output "config_path" {
  value = local_file.config.filename
}
END
cat > staging.tfvars <<'END'
environment = "staging"
owner       = "platform-team"
replicas    = 3
END
terraform init
terraform apply -var-file=staging.tfvars -auto-approve
terraform output
terraform output -raw app_name > app-name.txt
```

APPROACH
========
1. Create the folder and the three `.tf` files.
2. Write `staging.tfvars`.
3. `terraform init`, then `terraform plan -var-file=staging.tfvars` to check, then `terraform apply -var-file=staging.tfvars`.
4. `cat app.conf` and `terraform output`.
5. `terraform output -raw app_name > app-name.txt`

HINT
====
- `variable "environment" { type = string  description = "..." }`
- A multi-line string can be written as a heredoc: `content = <<-EOT ... EOT`.
- `terraform apply -var-file=staging.tfvars`
- `output "app_name" { value = random_pet.app.id }`

ORIGINAL SOLUTION SCRIPT (solve.sh)
===================================
#!/bin/bash
set -euo pipefail
mkdir -p /home/user/tf/app-config && cd /home/user/tf/app-config
cat > variables.tf <<'END'
variable "environment" {
  type        = string
  description = "Name of the environment"
}

variable "owner" {
  type        = string
  description = "Team that owns the application"
}

variable "replicas" {
  type        = number
  description = "Number of application replicas"
  default     = 1
}
END
cat > main.tf <<'END'
terraform {
  required_providers {
    local  = { source = "hashicorp/local" }
    random = { source = "hashicorp/random" }
  }
}

resource "random_pet" "app" {
  prefix = var.environment
}

resource "local_file" "config" {
  filename = "${path.module}/app.conf"
  content  = <<-EOT
    environment=${var.environment}
    owner=${var.owner}
    replicas=${var.replicas}
    app_name=${random_pet.app.id}
  EOT
}
END
cat > outputs.tf <<'END'
output "app_name" {
  value = random_pet.app.id
}

output "config_path" {
  value = local_file.config.filename
}
END
printf 'environment = "staging"\nowner       = "platform-team"\nreplicas    = 3\n' > staging.tfvars
terraform init -input=false >/dev/null
terraform apply -input=false -var-file=staging.tfvars -auto-approve >/dev/null
terraform output -raw app_name > app-name.txt
