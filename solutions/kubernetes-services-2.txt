QUESTION
========
## Objective

A ClusterIP Service is reachable only inside the cluster. A **NodePort** Service also opens a port on every node, so clients outside the cluster can reach the application at `<node address>:<node port>`. In this lab the cluster node is reachable from your terminal as `k3s`.

## Tasks

### Task 1: Deploy the application

Create a Deployment named `storefront` with `2` replicas and image `nginx:1.30.6-alpine`, container port `80`.

### Task 2: Create a NodePort Service

Create a Service:

- name: `storefront-np`
- type: `NodePort`
- selecting the `storefront` Pods
- port `80`, target port `80`
- node port `30080`

### Task 3: Access it from outside the cluster

From this terminal (which is outside the cluster), request `http://k3s:30080/` with `curl` and save the response to `/home/user/nodeport-response.html`.

### Task 4: Record the address

Create `/home/user/nodeport.txt` with:

```
node_ip=<internal IP of the cluster node>
node_port=<the node port of storefront-np>
url=<a URL that reaches the app through the node IP and port, for example http://10.0.0.5:30000/>
```

## Notes

- Node ports must be in the range 30000 to 32767.

## Expected outcome

`storefront-np` exposes the app on node port 30080, and the saved response is the Nginx page fetched from outside the cluster.

ANSWER
======
```bash
kubectl create deployment storefront --image=nginx:1.30.6-alpine --replicas=2 --port=80
kubectl rollout status deployment/storefront
cat <<'END' | kubectl apply -f -
apiVersion: v1
kind: Service
metadata:
  name: storefront-np
spec:
  type: NodePort
  selector:
    app: storefront
  ports:
    - port: 80
      targetPort: 80
      nodePort: 30080
END
curl -s http://k3s:30080/ > /home/user/nodeport-response.html
ip=$(kubectl get nodes -o jsonpath='{.items[0].status.addresses[?(@.type=="InternalIP")].address}')
printf 'node_ip=%s\nnode_port=30080\nurl=http://%s:30080/\n' "$ip" "$ip" > /home/user/nodeport.txt
curl -s "http://$ip:30080/" | head -5
```

APPROACH
========
1. Create the deployment.
2. Write a Service manifest with `type: NodePort` and `nodePort: 30080`, and apply it.
3. `curl http://k3s:30080/` and save the output.
4. Find the node IP and write `nodeport.txt`, then test the URL you wrote with `curl`.

HINT
====
- `kubectl expose deployment storefront --type=NodePort --name=storefront-np --port=80` picks a random node port. To choose `30080`, write a manifest with `nodePort: 30080` under `ports`, or edit the Service afterwards.
- `kubectl get nodes -o wide` shows the node's internal IP.

ORIGINAL SOLUTION SCRIPT (solve.sh)
===================================
#!/bin/bash
set -euo pipefail
kubectl create deployment storefront --image="$IMAGE_NGINX" --replicas=2 --port=80
kubectl rollout status deployment/storefront --timeout=300s
cat <<'END' | kubectl apply -f -
apiVersion: v1
kind: Service
metadata:
  name: storefront-np
spec:
  type: NodePort
  selector:
    app: storefront
  ports:
    - port: 80
      targetPort: 80
      nodePort: 30080
END
for _ in $(seq 1 30); do curl -sf http://k3s:30080/ > /home/user/nodeport-response.html && break; sleep 1; done
ip=$(kubectl get nodes -o jsonpath='{.items[0].status.addresses[?(@.type=="InternalIP")].address}')
printf 'node_ip=%s\nnode_port=30080\nurl=http://%s:30080/\n' "$ip" "$ip" > /home/user/nodeport.txt
